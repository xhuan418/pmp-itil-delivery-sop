# Agent Lifecycle Reference

Read the human guide at `docs/lifecycle-sop.md` for the full lifecycle explanation and use `templates/` to create working artifacts.

## Routing summary

| Need | Route |
|---|---|
| New initiative or customer ask | Intake, then initiate and align if it merits coordinated delivery |
| Repeatable, approved user demand | Service request |
| Service interruption | Incident: restore and communicate |
| Recurring or major interruption | Problem: investigate root cause after containment |
| Low-risk, repeatable, pre-authorized modification | Standard change |
| Material or risky modification | Normal change: assess, approve, test, implement, validate, record |
| Severe impact requiring urgent action | Emergency change: fast but controlled approval and post-review |
| Agile uncommitted product need | Backlog, product-owner prioritization |
| Delivery complete | Validate service readiness, hand over, close, capture lessons |

## Minimum customer update

State current status, user/business impact, current action, decision needed (if any), owner, and next update time.

## Minimum handover evidence

Named service owner, support/escalation route, knowledge/runbook, monitoring/access/security readiness, training, release validation, rollback path, and ownership of open risks/issues.
